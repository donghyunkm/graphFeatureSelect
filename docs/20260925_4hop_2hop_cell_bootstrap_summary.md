# 2026-09-25 — 4-hop vs 2-hop across all label groupings: cell-level paired bootstrap (consolidated)

**One place for every 4-hop-vs-2-hop comparison we have run, re-tested with a single, uniform
significance procedure.** Each per-experiment doc has its own Results/significance section; this doc
collects them so the arms can be read side by side. Numbers here are authoritative and regenerated by one
script — if a per-doc table disagrees, this doc (and the script) win.

## The test used here

**Cell-level paired bootstrap**, B = 10,000, fixed RNG seed 0 — `gfs/analysis/paired_cell_bootstrap.py`.
Each comparison has **5 matched seeds** per arm, and all test cells come from the **same biological
sample** (one mouse-isocortex val/test split; the partition is FIXED across seeds — seeds only randomize
training stochasticity). There is no donor/sample-level unit to resample, so we bootstrap **test cells**:

    for replicate b in 1..10000:
        idx = sample N_test cell indices WITH replacement          # ONE draw, shared by all 10 runs
        for seed s in 0..4:
            d[b,s] = F1_4hop(labels[idx], pred_4hop[s][idx]) - F1_2hop(labels[idx], pred_2hop[s][idx])
        delta[b] = mean_s d[b,s]                                    # paired within seed, averaged over seeds
    delta_obs   = mean_s (F1_4hop[s] - F1_2hop[s])                  # full, un-resampled test set
    95% CI      = [quantile(delta, .025), quantile(delta, .975)]
    p (2-sided) = min(1, 2 * min(mean(delta<=0), mean(delta>=0)))   # 0/10000 crossed -> reported "<0.0002"

The same cell resample is applied to all 5 seeds and both arms; pairing is preserved within seed; no model
is retrained (saved `test_pred.pt` predictions only). Observed Δ recomputed from `test_pred.pt`, verified
identical to the per-doc tables.

> ⚠️ **Scope caveat (applies to every row below).** *All cells are from one biological sample; bootstrap
> inference reflects cell-level uncertainty within this sample and does not establish across-sample
> biological generalization.* This test is far higher-powered than a seed-level paired test (it resamples
> ~31.5k cells, not 5 seeds) and **can disagree with the paired t-test**. The **paired t-test remains the
> primary test** for any cross-seed / generalization claim; the cell-level bootstrap is a within-sample
> statement and, where it flags significance the t-test does not, it corroborates *direction* only.
>
> This **supersedes** the earlier seed-level paired bootstrap (B=50,000) that appeared in the per-doc
> tables — those resampled only the 5 seed-level differences (anti-conservative at 5 clusters).

Note: across all these experiments the test set is essentially the **same ~31.5k cells**, just relabeled
per grouping (each variant keeps all cells; "keep a set + collapse the rest into `other`").

## The primary test: paired t-test over seeds

The **paired t-test is the primary, reported significance test** for these comparisons (the `t p` column
below). Procedure: for each of the 5 seeds compute the per-seed difference `d_s = F1_4hop(s) − F1_2hop(s)`
(pairing is exact — 2-hop seed_s and 4-hop seed_s score the identical test cells, labels element-wise
equal), then `t = mean(d) / (sd(d, ddof=1) / sqrt(5))` against t₄ (two-sided). Support statistics:
**Cohen dz** = `mean(d)/sd(d, ddof=1)` (paired effect size) and the **per-seed sign count** (how many of 5
seeds moved 4-hop's way).

**Why it, not the bootstrap or Wilcoxon, is primary:**
- It is the test that speaks to the question we actually care about — does the 4-hop gain **survive
  training-run stochasticity** (init / sampling / selection across seeds). The 5 seeds are the replicated
  unit for that claim; the cell-level bootstrap holds the seeds fixed and only asks about cell sampling
  *within* this one sample, so it cannot address generalization no matter how tiny its CI.
- At n=5 the t-test uses the fat-tailed t₄ reference and so is **conservative** (hard to clear α=0.05),
  whereas the cell-level bootstrap is **anti-conservative for the generalization question** (huge effective
  n from ~31.5k cells). They bracket the truth; we headline the conservative, correctly-scoped one.
- **Wilcoxon is deprecated here:** n=5 pins its minimum two-sided p at 0.0625, so it can never clear
  α=0.05 even on a clean 5/5 sweep — an uninformative floor. (It appears in some per-doc tables only as
  "maximally-in-favor-but-floored" context, never as the call.)

**Caveat on the t-test itself:** the val/test split is **fixed across seeds**, so the n=5 spread is
training-run stochasticity, not data/split uncertainty — and n=5 is low power. For a firmer claim, add
seeds or meta-analyze across grouping arms rather than switching tests. See the convention in `progress.md`
(Reference appendix) and memory `significance-convention-ttest-primary`.

## A seed-order-agnostic alternative: exact unpaired permutation test

The paired t-test matches 2-hop seed_s to 4-hop seed_s, but the two arms are **different architectures**,
so "seed 0 ↔ seed 0" is an essentially arbitrary matching of training-stochasticity draws. The exact
unpaired permutation test (`perm p` column) drops that matching and asks only whether the group of 5 4-hop
F1 values is shifted from the group of 5 2-hop values — **it never looks at seed identity**.

Procedure (`gfs/analysis/unpaired_permutation.py`): pool the 10 per-seed F1 values; `T_obs = mean(4-hop) −
mean(2-hop)`; enumerate **all C(10,5) = 252** ways to relabel 5 of the 10 as the "4-hop" group; two-sided
`p = (# permutations with |T| ≥ |T_obs|) / 252`. Exact (full enumeration), distribution-free. The observed
split and its mirror always qualify, so the two-sided **p floor is 2/252 = 0.0079** — much better than
paired Wilcoxon's 0.0625 floor at n=5, and low enough that a clean 5-vs-5 separation can clear α=0.05.

**Whether unpairing is appropriate is checkable, and the script prints it: the across-seed Pearson
correlation between the arms.** High positive correlation ⇒ the seed pairing captured real shared variance
⇒ the paired test is genuinely more powerful and unpairing throws that away. Near-zero ⇒ unpairing loses
almost nothing and is the more honest test.

**What the permutation test finds (α=0.05): three rows — abundant top-6 (both metrics, p=0.0079, the
permutation floor) and deep_sample Glut weighted (p=0.0079).** These are exactly the arms where the paired
t-test's win does *not* lean on the seed pairing: abundant's across-seed corr is only +0.40/+0.24 and Glut
weighted's is +0.07, so pairing bought little and the two tests agree.

**The one arm where the tests disagree is diverse6 maxdisp weighted** — paired t sig (p=0.016) but perm ns
(p=0.079). Its across-seed corr is **+0.79**, the highest in the table: the paired t-test earned that
significance *from* the strong pairing, and the order-agnostic test cannot see it. Read this as
pairing-dependent, not robust to dropping the seed matching. (gaba macro sits right at the edge both ways:
t p=0.066, perm p=0.063.)

**Bottom line:** under the stricter, assumption-free 5-v-5 view, the durable 4-hop wins are **abundant
top-6 (both metrics) and deep_sample Glut weighted**; diverse6 maxdisp weighted survives only the paired
test. The paired t-test remains primary for the generalization claim; the permutation column is the
robustness check on how much each call depends on the (arbitrary) seed matching.

## Reading the table

- **The bootstrap is significant almost everywhere; the t-test is not.** Because the cell sample is shared
  across seeds and F1 is averaged over ~31.5k cells, the bootstrap CIs are extremely tight — 20 of 22 rows
  clear α=0.05 on the bootstrap. Only **gaba_fine macro** (p=0.96) and **gaba_cge macro** (p=0.90) still
  have CIs crossing zero. This is a **power/scope** effect, not a discovery: it measures within-sample cell
  uncertainty, not whether the effect generalizes across seeds/samples.
- **By the primary paired t-test, only three arms clear α=0.05:** abundant top-6 (both metrics, 5/5 sweep),
  diverse6 **maxdisp weighted**, and deep_sample **Glut weighted**. Everything else is a t-ns trend.
- **The seed-order-agnostic permutation test (`perm p`) confirms two of those three and drops one:** abundant
  top-6 (both metrics) and Glut weighted stay significant (all at the 0.0079 floor); **diverse6 maxdisp
  weighted flips to ns (perm p=0.079)** because its t-test win rode a strong seed pairing (across-seed corr
  +0.79). So the wins robust to *how* seeds are matched are abundant top-6 + Glut weighted. See the
  permutation-test section above.
- **full22 macro is the sharpest disagreement:** cell-level CI is entirely **below** zero (4-hop worse on
  macro on this sample), while the t-test calls it a tie. The headline conclusion (4-hop ties 2-hop on full
  22-label data) rests on the t-test and is unchanged — see memory `4hop-does-not-beat-2hop-full-data`.
- **Ceiling-bound weighted rows** (all Gaba variants: 0.98–0.99) show tiny but bootstrap-"significant" Δ's
  (+0.0005 to +0.0010). The effect is real on this sample but negligible in size and t-ns — near ceiling
  there is almost no headroom, so read these as ties.
- **The one substantive-but-t-ns signal the bootstrap strongly backs is MGE macro (+0.0541, boot p<0.0002)**
  — the rare mid-deep laminar interneuron types (Sst-Chodl / Pvalb-chandelier / Lamp5-Lhx6). Directionally
  matches the CGE-vs-MGE hypothesis; the t-test stays ns at n=5 (memory `gaba-finegrained-4hop-not-significant`).
